Modellverwaltung

Das Modell wird beim ersten Generieren automatisch heruntergeladen. Beim Wechsel entlädt das System das bisherige Modell, um VRAM freizugeben. Ein Modell bleibt danach bis zum Wechsel im Speicher.

API & Integration

API-Dokumentation: /api/docs. Endpunkt: POST /api/generate, anschliessend GET /api/jobs/{id} abfragen und Audio über GET /api/audio/{id} abrufen.

Für LAN-Zugriff in config.env HOST auf 0.0.0.0 stellen und zwingend einen langen API_TOKEN vergeben. Für dauerhaften Einsatz über Netz: TLS-Reverse-Proxy und Zugriffsbeschränkungen einrichten.

Diagnose & Daten

Der Dump enthält Systemzustand und Log-Datei, jedoch keine Audiodateien, vollständigen Sprachtexte oder API-Tokens. Fehler können trotzdem technische Pfade enthalten.
